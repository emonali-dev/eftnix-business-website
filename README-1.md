# EFTNIX Business Website Demo

A responsive portfolio-style business website demo for EFTNIX.

## Sections
- Hero and brand introduction
- Digital services
- Project workflow
- Selected demo concepts (clearly labelled as illustrative)
- About EFTNIX
- Contact inquiry form (opens the visitor's email app; no backend storage)

## Run locally
Open `index.html` in a modern browser.

## GitHub Pages
Repository Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

## Before commercial use
Review and replace the sample email address `hello@eftnix.com` with a verified address you control. Update brand, service, and portfolio details to match your actual offerings. The contact form is a front-end demo and does not store or transmit inquiries to a server.
